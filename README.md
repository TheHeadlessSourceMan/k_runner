# k_runner
More seamlessly run system programs with python.

(Lightyears beyond Popen!)

NOTE: THIS IS EXPERIMENTAL AND IS SUBJECT TO CHANGE

Features:
* wrap system program and then call it like a function
* load/save this configuration to json
* work with stdout, stderr, and both combined -- all at the same time
* stream the results live
* filter streams
* call function when something happens on a stream.
* save results to json
* describe commands in xml (works on in html too)
  * includes tiny rest server to execute commands from html click events
